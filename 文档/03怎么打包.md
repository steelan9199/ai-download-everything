## 二、发给别人后，对方怎么用

我已经把这些写成了一份纯文本说明（上面第二个链接），你可以和 exe 一起发给对方，核心流程是：

1. **双击 exe**：绿色版免安装，首次启动会慢几秒（后台临时解压）。
2. **过蓝色安全提示**：因为没买数字签名，会弹「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」；杀软可能误报，选信任即可。
3. **装两个辅助工具（只需一次）**：ffmpeg 和 yt-dlp 不打包在 exe 里（项目刻意不塞二进制）。对方以管理员身份开 PowerShell，跑两行 `winget install Gyan.FFmpeg` 和 `winget install yt-dlp.yt-dlp`，然后重启软件；不会命令行就手动下载、在「设置」页用「浏览」填路径（说明里都有链接和步骤）。
4. **确认下载目录**：设置页里默认是「下载\AI下载视频」文件夹，可改。
5. **粘贴链接 → 点下载**：快手短链直接解析直链秒下；普通网站走内置引擎；难站会弹内置浏览器窗口，按屏幕上的提问点选即可，不用打字。

## 三、必须知道的注意事项

- **微信/QQ 不要直接发 exe**：容易被拦截或改后缀。建议先把 exe 压成 zip 再发，或走网盘/U盘；对方从网盘下载后若打不开，右键 exe → 属性 → 勾「解除锁定」。
- **环境门槛**：测试者电脑必须是 Win10/11 64 位，且 ffmpeg、yt-dlp 缺失时软件会在顶部横幅给出指引、不放行下载——所以测试前务必确认对方完成了第二步。
- **配置不丢**：绿色版的设置、站点规则存在本机 `%APPDATA%\ai-video-downloader`，对方以后换新 exe 覆盖使用，配置还在。
- **「问 AI」用不了是正常的**：那是可选高级功能，需要自己填 API Key，普通下载和快手都用不到。
- **yt-dlp 会过时**：个别网站过几个月可能突然不支持，让对方重跑一次 `winget install yt-dlp.yt-dlp` 更新即可。
- 软件不上传任何数据，Cookie 只存本机；提醒测试者仅供个人学习、遵守版权。
