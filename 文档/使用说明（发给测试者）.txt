============================================================
 AI 视频下载器 · 使用说明（测试版）
============================================================

【这是什么】
一个 Windows 小工具：把视频网页链接粘进去，点“下载”，
视频就会保存成 mp4 文件到你电脑上。
支持快手等短视频站，以及大量普通视频网站。
仅供个人学习使用，请遵守版权和各网站规定。

【适用系统】
Windows 10 / Windows 11，64 位电脑。不支持手机和 Mac。

------------------------------------------------------------
 第一步：第一次打开（会有蓝色安全提示，正常现象）
------------------------------------------------------------
1. 双击 “AI视频下载器-v0.1.0.exe”。
   （这是绿色单文件版，不用安装；首次启动会慢几秒，
     它会在后台临时解压，请耐心等一下。）

2. 如果弹出蓝色窗口 “Windows 已保护你的电脑”：
   这是因为软件没有花钱买数字签名，不是病毒。
   点窗口里的 “更多信息” → 再点 “仍要运行” 即可。

3. 如果杀毒软件（360、火绒、Windows 安全中心等）报风险：
   属于未签名小工具的常见误报，选择“允许/信任”即可；
   不放心可以先不运行并反馈给发你软件的人。

------------------------------------------------------------
 第二步：准备两个辅助工具（只需做一次）
------------------------------------------------------------
本工具本身不含 ffmpeg 和 yt-dlp 两个辅助程序，
第一次使用前需要让电脑具备它们（设置页里也有同样的提示）：

★ 方法一（推荐，会用命令行的话最快）：
  1) 按 Win 键，输入 PowerShell，右键“以管理员身份运行”；
  2) 分别粘贴下面两行、每行回车，等它装完：

        winget install Gyan.FFmpeg
        winget install yt-dlp.yt-dlp

  3) 装完后把软件完全关掉、重新打开一次。

★ 方法二（不想用命令行）：
  1) ffmpeg：浏览器打开 https://www.gyan.dev/ffmpeg/builds/
     下载 “release full” 的压缩包，解压到一个固定文件夹；
  2) yt-dlp：浏览器打开 https://github.com/yt-dlp/yt-dlp/releases
     下载 yt-dlp.exe，保存到一个固定文件夹；
  3) 打开本软件 → 点顶部“设置”→ 用“浏览”按钮分别选中
     ffmpeg.exe 和 yt-dlp.exe → 点“保存设置”。

------------------------------------------------------------
 第三步：开始下载
------------------------------------------------------------
1. 打开软件后，先点“设置”，确认“下载目录”是你想存视频的
   文件夹（默认存在 我的文档旁边的“下载\AI下载视频”里），
   不对就点“浏览”改一个，然后“保存设置”。

2. 回到“下载”页：
   - 把视频链接粘贴到输入框；
   - 点“下载”。

3. 然后会发生什么：
   - 直接可解析的站：几秒到几十秒下完，
     点“打开文件夹并选中文件”就能看到 mp4；
   - 普通网站：自动用内置引擎下载，有进度条；
   - 个别难打开的网站：会弹出一个内置浏览器窗口让你
     看网页（可能需要你登录、过滑块验证），按软件弹出的
     提示点一下选项即可，它会在后台抓视频。

4. 下载中途软件弹出提问框时，按你看到的实际情况点选就行
   （比如“我已完成验证并点播放了”），不用打字。

------------------------------------------------------------
 常见问题
------------------------------------------------------------
· 提示“运行环境还没就绪”：
  说明第二步没做或没装好，按“设置”页里的文字指引处理。

· 下载失败 / 卡住：
  把链接重新粘一次再点下载；难站就在弹出的浏览器窗口里
  先让视频正常播放起来，再按提示操作。

· yt-dlp 用久了个别网站突然不支持：
  它在持续更新，重新执行一次 winget install yt-dlp.yt-dlp
  （或重新下载 yt-dlp.exe 替换）即可。

· “问 AI”功能用不了：
  正常，那是可选的高级功能，需要自己填大模型 API Key，
  普通下载完全用不到。

------------------------------------------------------------
 隐私与安全
------------------------------------------------------------
· 软件不需要注册登录，不会上传你的任何文件；
· 浏览网页时产生的 Cookie 只保存在你自己电脑上，
  用于过网站验证，不会发给任何人；
· 设置信息保存在本机，换电脑不带走。

------------------------------------------------------------
 转发软件的小提示（给发文件的人看）
------------------------------------------------------------
· 微信/QQ 直接发 .exe 可能被拦截或改后缀，建议先把
  exe 压缩成 .zip 再发，或用网盘/U盘传；
· 对方下载网盘文件后，Windows 可能给文件加上“锁定”，
  解压后右键 exe → 属性 → 勾选“解除锁定”→ 确定。
